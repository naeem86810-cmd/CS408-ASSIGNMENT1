## ⚙️ Installation and Execution

### Prerequisites

Install the following software before running the project:

* Node.js
* npm
* Visual Studio Code
* Git

### Step 1: Open the Project

Open the project directory in Visual Studio Code.

### Step 2: Verify Installation

Run these commands in the terminal:

```bash
node -v
npm -v
git --version
```

### Step 3: Initialize npm

If the project has not already been initialized, run:

```bash
npm init -y
```

### Step 4: Run the Application

Execute:

```bash
node app.js
```

### Expected Output

```text
Welcome to Node.js!
Course: CS-408 Student
Project is running successfully.
```

## 🔄 Git Workflow

The following commands demonstrate a basic Git workflow:

```bash
git status
git add .
git commit -m "Update assignment files"
git push
```

These commands check the repository status, stage changes, create a commit, and push committed changes to the configured remote repository.

## 🔒 Git Ignore Configuration

The `.gitignore` file contains:

```gitignore
node_modules/
.env
```

This prevents untracked dependencies and environment files from being added to Git.

**Security reminder:** Never upload passwords, API keys, access tokens, or other confidential information to a public repository.
